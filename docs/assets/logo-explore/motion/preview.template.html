OpenGateway logo motion

In the product the logo stays still. It is on screen all day, so it only moves on a first-run splash, a loading screen, a docs or release hero, and when a connection changes state. Sound is off until you enable it, plays once per moment, and is never attached to a loop. Everything here respects prefers-reduced-motion by showing the static mark.

Sound is synthesised in your browser. Press Replay on a card to hear it. Muted below 1x speed.
